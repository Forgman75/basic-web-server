# basic-web-server


# Простейший HTTP-сервер на Python

## Описание проекта

Учебный проект представляет собой простейший веб-сервер, реализованный с использованием встроенной библиотеки Python `http.server`.

Сервер принимает HTTP-запросы от клиента, отправляет HTML-страницы и CSS-файлы, а также обрабатывает данные, переданные через HTML-форму методом POST.

## Возможности

- Обработка GET-запросов.
- Отправка HTML-файла клиенту.
- Отправка CSS-файла клиенту.
- Обработка POST-запросов.
- Получение данных из HTML-формы.
- Вывод полученных данных в консоль сервера.
- Отправка ответа клиенту после обработки запроса.

## Используемые технологии

- Python 3
- HTTP
- HTML
- CSS
- HTTP GET и POST

Используются встроенные модули Python:

- `http.server` — создание и запуск HTTP-сервера.
- `pathlib` — работа с путями к файлам.
- `urllib.parse` — обработка данных HTML-формы.

Дополнительные библиотеки устанавливать не требуется.

## Запуск проекта

1. Скачайте или скопируйте проект на компьютер.
2. Откройте терминал в корневой папке проекта.
3. Запустите сервер командой:

   ```bash
   python server.py
   ```

4. Откройте браузер и перейдите по адресу:

   http://localhost:8080

Для остановки сервера нажмите `Ctrl + C` в терминале.

## Обработка GET-запросов

Метод `do_GET()` отвечает за обработку GET-запросов.

Сервер поддерживает следующие маршруты:

| Маршрут | Назначение |
|---------|------------|
| `/` | Отправка файла index.html |
| `/styles.css` | Отправка файла styles.css |

При обращении к серверу браузер получает HTML-документ.

Если в HTML-документе подключён CSS-файл, браузер автоматически отправляет дополнительный GET-запрос для его загрузки.

## Обработка POST-запросов

Для отправки данных на сервер используется HTML-форма.

Пример формы:

```html
<form action="/submit" method="POST">
    <label for="message">Введите сообщение:</label>

    <input
        type="text"
        id="message"
        name="message"
        required
    >

    <button type="submit">Отправить</button>
</form>
```

При нажатии кнопки «Отправить» браузер отправляет POST-запрос на маршрут `/submit`.

Метод `do_POST()` выполняет следующие действия:

1. Проверяет адрес запроса.
2. Получает размер переданных данных.
3. Считывает тело HTTP-запроса.
4. Декодирует полученные данные.
5. Преобразует данные формы в словарь с помощью `parse_qs`.
6. Извлекает значение поля `message`.
7. Выводит полученное сообщение в консоль.
8. Отправляет клиенту ответ об успешном получении данных.

Пример вывода в консоли:

```text
Получено сообщение от клиента: Привет, сервер!
```

Ответ сервера:

```text
Сообщение успешно получено сервером!
```
